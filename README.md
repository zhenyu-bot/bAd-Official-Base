# 🏸 bAd Official Repository

bAd is a non-profit organization. This repository is for sharing the officially certified history, organization structures, policy, and applications of bAd with the student badminton amateur around the world (only for China till now). This repository collects all core materials of bAd, including event recordings, badminton-related AI application projects, ranking data, historical documents, management policies and organizational structures. It fully records the growth and development of our badminton community.

---

## 📂 Repository Structure
bAd-Official-Base/

├── Activity-Recordings/ 🎥 Photos & videos of major events

├── Contributions-on-Apps/ 🤖 AI-assisted badminton training codes & applications

## 📁 File & Folder Introduction

### 🎥 Activity-Recordings
Collection of visual records for all major tournaments and group activities:
- Highlight moments of competitions
- Group photos and activity clips
- Full recordings of official matches

### 🤖 Contributions-on-Apps
Technical resources for **AI-assisted badminton training**:
- Motion analysis algorithms
- Source code of training applications
- Related data tools and scripts

### 📊 Score-Ranking
Official scoring and ranking documents:
- Technical reports of the scoring system
- Full-cycle regional leaderboards
- Detailed ranking rules

### 📜 History.docx
Complete archive of bAd’s development:
- Foundation background & original vision
- Key milestones and important events
- Development timeline

### 📋 Important Policy.docx
Official management guidelines:
- Unified management framework
- Detailed rules for all departments
- Daily operation standards

### 🏗️ Organization Structures.docx
Latest organizational layout of bAd:
- Management hierarchy charts
- Responsibilities of each department
- Staff division arrangements
